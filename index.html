The problem

AI agents are smart. They cannot transact.

For agent developers

Want your agent to generate a PDF, process an image, or run a workflow? You integrate Stripe + Resend + Slack + 5 more APIs. Each with its own auth, billing, error format. 1 feature = 1 week of work.

For service providers

You have an API users would love. AI agents would integrate it — but each agent SDK (OpenAI, Anthropic, LangChain, LlamaIndex…) needs its own integration. The ROI doesn't justify it.

For the ecosystem

Autonomous agents need budget controls. None of the existing protocols (MCP, A2A) include payment authorization. Runaway agents drain wallets without warning.

30-second quickstart

3 steps. No subscription. Apache 2.0.

01

Register

Get an agent_id + api_key with 100 free calls.

curl -X POST https://jecp.dev/api/agents/register \
  -H "Content-Type: application/json" \
  -d '{"name":"My Agent","agent_type":"automation"}'
02

Execute

Call any of 25 actions. Get the artifact in 127ms.

curl -X POST https://jecp.dev/v1/jecp \
  -H "X-Agent-ID: $AID" -H "X-API-Key: $KEY" \
  -d '{"jecp":"1.0","id":"req_001",
       "capability":"document-pipeline",
       "action":"generate-invoice",
       "input":{...}}'
03

Top up

When free runs out, pay $5 / $20 / $100. Balance never expires.

curl -X POST https://jecp.dev/api/agents/topup \
  -H "X-Agent-ID: $AID" -H "X-API-Key: $KEY" \
  -d '{"amount":5}'
# → Stripe Checkout URL

Mandate

Pre-authorize a budget per call. The hub auto-rejects overruns. Stops runaway agents from draining wallets.

Trust Gate

Bronze → Silver → Gold → Platinum. Higher tiers unlock more capabilities and rate limits. Earned by paid usage.

next_action

Every error response includes a machine-readable recovery step. Agents auto-recover without human help.

Open spec

Apache 2.0. Anyone can run their own JECP server. The protocol is independent of any single vendor.
