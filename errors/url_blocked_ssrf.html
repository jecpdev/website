Errors / url_blocked_ssrf

URL_BLOCKED_SSRF

HTTP 422Spec: §9.7 · ADR-0002

What it means

The Hub refused to dereference an Agent-controlled URL because the URL hits the JECP SSRF deny-list. The URL itself was structurally well-formed — a valid HTTP URL syntactically — but its scheme, host, or resolved IP violated the policy specified in spec §9.7.1.

This is a security policy rejection, not a wire-format validation failure (INPUT_SCHEMA_VIOLATION) and not a transient transport error (PROVIDER_UNREACHABLE).

When it fires

Conformant Hubs run the validation pipeline at BOTH register-time (so legitimate Providers / Agents get fast feedback) AND deref-time (so DNS-rebinding between register and use is caught).

Reason registry

parse_error

URL did not parse per RFC 3986. Fix: send a syntactically valid HTTP URL. Most often this is a missing scheme (example.com instead of https://example.com) or an unescaped fragment.

scheme

Scheme was not https (or http outside test mode). Fix: use https:// in production. http:// is rejected even when the host is otherwise valid — there's no operator override for this in the public Hub.

host_syntax

Host was percent-encoded, contained credentials (user:pass@), or used a non-public TLD with no DNS resolution. Fix: normalize to plain ASCII / IDN-decoded form. Strip embedded credentials — JECP uses X-API-Key, not basic auth.

resolved_to_deny_cidr

Hostname resolved to a deny-list CIDR (RFC1918, loopback, link-local, CGNAT, IPv6 ULA, etc.). Fix: use a domain name that resolves to a public IP. For staging integration with private hosts, ask the Hub operator to extend the allowlist for your namespace.

dns_resolve_failed

The hostname did not resolve (NXDOMAIN, NODATA, or all resolvers timed out). Fix: confirm the A/AAAA records exist and are reachable from a public DNS server (dig @8.8.8.8 +short <host>). Wildcard DNS providers sometimes drop sub-domain queries — verify your records actually publish.

connect_pin_violation

The resolver returned a different address at connect() than at validation (DNS rebinding). Fix: stop using TTL-1 / split-horizon DNS for the affected hostname. Conformant Hubs implement IP-pinning at the HTTP-client layer to prevent the rebinding window from being exploitable.

For async deref paths (webhook delivery)

The Hub does not return this envelope synchronously — the originating subscription request already returned 200. Instead the Hub marks the outbox row abandoned_at = NOW(), reason = 'SSRF_DENIED', logs the rejection in ssrf_attempts (per §9.7.1.4), and stops retrying. Hub operators surface the audit trail via dashboard or webhook delivery report endpoints.
