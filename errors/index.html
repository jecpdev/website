Error catalog

Every error returned by a conformant JECP Hub carries a documentation_url that resolves to this catalog. Each entry below documents the HTTP status, when the error fires, structured details fields, and the 30-second recovery action.

How to read these pages

Errors return as a wrapped envelope per spec §3:

{
  "jecp": "1.0",
  "status": "failed",
  "error": {
    "code": "URL_BLOCKED_SSRF",
    "message": "...",
    "details": {
      "field": "endpoint_url",
      "reason": "resolved_to_deny_cidr",
      "documentation_url": "https://jecp.dev/errors/url_blocked_ssrf#resolved_to_deny_cidr"
    }
  }
}

Some errors carry sub-categories (subcause, reason). Their documentation_url deep-links to the relevant anchor on the page below — the recovery action there is the specific one for that branch.

Catalog

CodeHTTPWhat it means
capability_deprecated 410 The capability is past its sunset date. details.successor names the replacement when one exists.
duplicate_request 409 The idempotency id was reused for a different request body. Use a fresh id per logical request.
input_schema_violation 400 The action input failed JSON Schema validation. details.errors[] lists every failed assertion.
insufficient_balance 402 The Agent's wallet balance is below the action's quoted price. Top up via jecp topup or fund the Base wallet.
insufficient_budget 402 The mandate.budget cap was below the action's quoted price. Raise the mandate budget or pick a cheaper action.
provenance_mismatch 403 The mandate.provenance_hash failed verification. Common subcauses: clock skew, nonce replay, v1/v2 wire mismatch.
rate_limited 429 The Agent exceeded the per-IP / per-Agent rate limit. details.retry_after_seconds mirrors the Retry-After header.
unsupported_media_type 415 The request Content-Type was not application/json. Send valid JSON with the right header.
url_blocked_ssrf 422 An Agent-controlled URL hit the SSRF deny-list. Branches by details.reason: scheme / resolved_to_deny_cidr / etc.

Where these come from

The catalog mirrors the canonical spec definition in jecp-spec / 03-errors.md and the reference catalog files at spec/error-catalog/. If a page here disagrees with the spec, the spec wins — please file an issue.

Reporting issues

If the recovery action listed here didn't work, or you hit an error code not listed above, open an issue at github.com/jecpdev/website/issues with the full error envelope from the response body. Don't redact details — that's where the fix usually is.
